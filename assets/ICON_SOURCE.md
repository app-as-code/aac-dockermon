# Icon source

The icon is downloaded from the dashboard-icons collection (repository `homarr-labs/dashboard-icons`,
served via jsdelivr). No icon was drawn or modified by hand.

The upstream project (`philhawthorne/ha-dockermon`) does not ship a logo. The Docker whale
was chosen because the service monitors the Docker daemon. It is the Docker brand mark, not
a logo of the Dockermon project itself.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/docker.svg` | Default for all color schemes |

No light or dark variants exist for this icon in the collection, so only `icon.svg` is provided.

Download URL:

- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/docker.svg
